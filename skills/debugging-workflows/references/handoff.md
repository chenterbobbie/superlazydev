# Bug-fix handoff

Write for the next person who needs to continue or verify the work. Keep confirmed evidence distinct from hypotheses.

## Handoff format

- **Status:** fixed, investigated, or still blocked; do not overstate completion.
- **Symptom:** observed behavior and expected behavior.
- **Evidence:** reproduction steps, logs, or relevant conditions; state when reproduction was unavailable.
- **Cause:** verified root cause, or leading hypothesis labeled as such.
- **Changes:** paths changed and the effect of each change.
- **Validation:** exact checks or scenarios run and their results; list important gaps.
- **Next step:** one concrete action if work remains.

Include only details that help continuation. Do not include secrets, credentials, or unrelated repository context.
